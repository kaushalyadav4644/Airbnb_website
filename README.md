# Wanderlust (Airbnb Clone)

A full-stack web application inspired by Airbnb, built using Node.js, Express, and MongoDB. It allows users to explore listings, view details, and manage property rentals.

## 🚀 Features
* **User Authentication & Authorization:** Secure signup, login, and session management.
* **Listings Management:** Browse, create, update, and delete property listings.
* **Responsive Design:** Optimized layout for both desktop and mobile devices using custom media queries.
* **Cloud Storage:** Image uploads integrated securely with cloud storage configuration.

## 🛠️ Tech Stack
* **Frontend:** EJS (Embedded JavaScript), CSS3, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB & Mongoose ODM
